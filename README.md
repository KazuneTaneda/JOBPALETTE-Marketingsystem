# JOBPALETTE Marketing System

求人広告（求人ボックス・Indeed・Engage・ジモティ等）の応募者データを一元蓄積し、AI が分析・週次/月次レポート生成・求人改善提案までを担う体制を構築するシステム。

現在は**要件定義フェーズ**（実装未着手）。要件定義書: [docs/requirements/README.md](docs/requirements/README.md)

## 全体像（2フェーズ構成）

1. **フェーズ1（本リポジトリで今取り組む範囲）**: データ基盤＋自動分析＋週次/月次振り返りレポート
   - ローデータ蓄積 → 自動分析 → レポート生成 → 人間は意思決定だけ、という体制を作る
2. **フェーズ2（フェーズ1稼働後に着手）**: 上流の月次戦略計画（来月どの媒体・アカウント・求人にどう配分するか）の自動化
   - フェーズ1で見えた課題・パターンを踏まえて設計する。詳細は現時点では確定させない（[09_open_questions.md](docs/requirements/09_open_questions.md) 参照）
   - 姉妹システムの [dr-system](https://github.com/KazuneTaneda/dr-system)（ダイレクトリクルーティングの月次計画システム）と同じ「実績蓄積 → 振り返り → 翌月計画の叩き台 → 人が確定」という型を踏襲する想定
