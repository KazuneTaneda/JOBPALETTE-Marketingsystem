# 05. KPI定義

## 最重要KPI: 35歳以下の有効応募

マーケ側の最重要ミッションは「とにかく35歳以下を集めること」。

- IS側の架電からのアポ獲得率は約3.5%程度を見込めており、架電工数も確保する方向
- → マーケ側が質の高い母集団（35歳以下の有効応募）を作れば、後工程（IS〜面談〜推薦）は回せる、という整理
- 分析で特に明確にしたいのは、媒体 → アカウント → 求人 → 応募者属性 まで掘ったときに「どこから35歳以下の応募が来ているのか」

評価の考え方: **単純にCPAが高い・安いでは評価しない**。CPAが高くても35歳以下の有効応募が取れていれば許容できる。逆にCPAが低くても35歳以上ばかりなら評価を下げる。dr-system の `judgment.ts`（前月比判定の純関数）と同様、複合的な評価ロジックを関数として明示的に実装する想定。

## A系: 総論（キャンペーン／媒体／アカウント単位）

| KPI | 定義（分子/分母、粒度） |
|---|---|
| 応募数 | 期間内の応募合計。媒体／アカウント／職種大分類／地域で集計可能 |
| クリック率 | クリック数 ÷ 表示回数（媒体側の提供値に依存） |
| CPA | 広告費 ÷ 応募数 |
| 有効応募率 | 有効応募数 ÷ 応募数（「有効応募」の定義は [09 Q-05](09_open_questions.md)） |
| 35歳以下応募率 | 35歳以下の応募数 ÷ 応募数 |
| 地域別応募構成 | 応募数を地域（一都三県／大阪／名古屋／福岡を重視）で按分 |
| アカウント別成果 | 上記指標をアカウント単位で集計 |
| 職種大分類別成果 | 上記指標を職種大分類単位で集計 |

## B系: 各論（応募者／求人単位）

| KPI | 定義 |
|---|---|
| 35歳以上比率 | 35歳以上の応募数 ÷ その求人の応募数 |
| 35歳以下比率 | 35歳以下の応募数 ÷ その求人の応募数 |
| 外国籍比率 | 外国籍の応募数 ÷ その求人の応募数 |
| 有効応募率 | 有効応募数 ÷ その求人の応募数 |
| 地域 | その求人の勤務地 |
| 職種 | その求人の職種 |
| 求人別CPA | その求人の広告費 ÷ その求人の応募数 |

異常検知の例: 「シニアが異常に多い求人」（35歳以上比率が全体平均・同職種平均から大きく乖離）、「外国籍応募が偏る求人」（外国籍比率が異常に高い）を自動フラグする。

## 人材紹介事業KPI

- **存続ライン**: 営業利益率15%を確保する（売上1,000万円の場合、コスト約850万円・営業利益約150万円という想定）
- **可視化する工程**: 応募 → IS → 面談設定 → 面談実施 → 推薦
  - 必須: 日次稼働、推薦数、面談設定数、面談実施数
  - 中間工程（架電数など）は後回しでよい
  - データソース: HubSpot等（[09 Q-10](09_open_questions.md) でどのプロパティ/パイプラインを参照するか確認）

## 既に見えている仮説（分析基盤ができ次第、検証対象にする）

- WorkEdge: 35歳以上応募が比較的少ない。35歳以上比率は約20%
- MIRIZE／Assist／Openpath: 35歳以上応募がかなり多い
- 「20代活躍中」と書くだけでは若年層フィルターとしてほぼ機能していない求人がある → タイトル・仕事内容・給与・勤務地・職種・媒体・アカウント等を特徴量として掘る分析が必要
