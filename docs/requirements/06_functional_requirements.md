# 06. 機能要件

## FR-DATA: データ取込・蓄積

- FR-DATA-01: 求人ボックス・Indeed・Engage・ジモティ等のローデータを、期間を区切らず一元的なデータストアに蓄積できる
- FR-DATA-02: 取込方法は媒体ごとのデータ提供形式に依存する（CSV手動アップロード／API連携／未整備、のいずれか。[09 Q-02](09_open_questions.md)）
- FR-DATA-03: 取込データは物理削除せず、修正時は履歴が追える形で保持する

## FR-ANA: 自動分析

- FR-ANA-01: 総論（媒体／アカウント単位）の指標を自動集計できる（[05 KPI定義](05_kpi_definitions.md) A系）
- FR-ANA-02: 各論（求人／応募者単位）の指標を自動集計できる（同 B系）
- FR-ANA-03: 媒体 → アカウント → 求人 → 応募者属性の掘り下げ分析ができる
- FR-ANA-04: CPAの高低のみで評価せず、35歳以下有効応募率との複合評価ロジックで媒体・アカウント・求人を評価する
- FR-ANA-05: 「シニアが異常に多い求人」「外国籍応募が偏る求人」等の異常を自動検知する
- FR-ANA-06: 求人の特徴量（タイトル・仕事内容・給与・勤務地・職種・媒体・アカウント）と35歳以下応募率の関係を分析できる

## FR-REP: レポート生成

- FR-REP-01: 週次で自動的にレポートを生成する（人手を介さず定期実行される）
- FR-REP-02: レポートには最低限、全体応募数・有効応募数・35歳以下率・35歳以上率・外国籍率・CPA・有効応募CPA・媒体別・アカウント別・職種別・地域別・ワースト求人・ベスト求人・前週比・次週アクションを含む
- FR-REP-03: 生成したレポートを蓄積し、前週・過去との比較ができる
- FR-REP-04: レポートを指定先（[09 Q-03](09_open_questions.md) で確定）に自動配信できる

## FR-ACT: 改善アクション提案

- FR-ACT-01: 分析結果から具体的な求人アクション案（「○職種を○本追加」「このアカウントに○求人追加」「CPA○円以内を目標」「この求人は停止／修正」等）を生成する
- FR-ACT-02: アクション案は採用/却下/修正のステータスを持ち、人間の意思決定結果を記録できる

## FR-HUB: 人材紹介ファネル連携

- FR-HUB-01: HubSpot等から応募 → IS → 面談設定 → 面談実施 → 推薦 の主要工程データを取得できる
- FR-HUB-02: 日次稼働・推薦数・面談設定数・面談実施数を週次/月次レポートに含める

## FR-ADM: 運用・管理

- FR-ADM-01: 「有効応募」等、業務上の定義が必要な用語は明示的にマスタ／設定として管理する
- FR-ADM-02: 不明な業務ルールは推測で実装せず、[09 未決事項](09_open_questions.md) に記録してレビューを仰ぐ
