# 07. 非機能要件（ドラフト）

技術構成（[09 Q-01](09_open_questions.md)）が確定していないため、詳細は仮置き。dr-system の方針を参考にしている箇所は明記する。

## 個人情報

- 応募者の氏名・電話・メール等、個人を特定する情報は原則蓄積しない。年齢区分・国籍区分・地域・有効応募フラグ等の**属性データのみ**を扱う方針（dr-system D-11相当）→ 要確認 [09 Q-09](09_open_questions.md)
- 媒体アカウントのパスワード等の認証情報はシステム・ドキュメント・シードデータに書かない

## 監査性

- マスタ・実績データは物理削除せず、無効化のみとする
- 更新系の操作は誰が・いつ・何を変更したか記録する（監査ログ）

## 権限

- 少なくとも「閲覧のみ」「編集可能」の区分を想定。詳細ロールは利用者確定後に設計（鈴木さんに加え、部下の方も共同編集する想定のため）

## AI利用

- 分析・レポート生成にLLM APIを利用する場合、渡すデータは集計値・匿名化された属性データに限定し、個人情報を含む生データをAPIに渡さない

## 保守性

- 「有効応募」等の業務用語の定義は設定として一元管理し、コード中にハードコードしない
- 不明な業務ルールは推測実装せず [09 未決事項](09_open_questions.md) に記録する
